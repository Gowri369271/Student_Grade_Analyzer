# Student Grade Analyzer

A console-based Java application for managing student records and calculating academic performance.

## Features

- Add student name, roll number, and subject marks
- Calculate total marks and average
- Assign grades based on average
- Display all student records
- Search for students by name
- Sort students by total marks
- Find the top scorer
- View grade distribution
- Update existing student marks

## Grade Criteria

| Average | Grade |
|---|---|
| 90 or higher | A |
| 75–89 | B |
| 60–74 | C |
| 40–59 | D |
| Below 40 | F |

## Requirements

- Java Development Kit (JDK) 8 or later
- A terminal or command prompt

## Running the Application

1. Clone the repository:

```bash
git clone https://github.com/Gowri369271/Student_Grade_Analyzer.git
```

2. Navigate to the project directory:

```bash
cd Student_Grade_Analyzer
```

3. Compile the Java file:

```bash
javac "Main (1).java"
```

4. Run the application:

```bash
java Main
```
